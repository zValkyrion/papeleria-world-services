# Gemini Skills

This directory will contain custom Gemini skill implementations.

Each skill should be placed in its own subdirectory with a clear README describing its purpose, inputs, and outputs.

## Suggested Structure
```
gemini_skills/
│   README.md
│
├── my_skill_one/
│   ├── main.py   # or .js, .sh, etc.
│   └── README.md
└── another_skill/
    └── ...
```
